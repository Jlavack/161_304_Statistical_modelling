## Exercise 1: Die entropy
### 7E3
Suppose a four-sided die is loaded such that, when tossed onto a table, it shows “1” 20%, “2” 25%, “3” 25%, and “4” 30% of the time. What is the entropy of this die?

Entropy is the average log-probability of an event given by the equation:

$$ H(p) = - \mathbb{E} \log(p_i) = - \sum_{i=1}^{n}  p_i \log(p_i) $$


Thus, for each probability $p_i$, we multiply $p_i$ by $\log(p_i$), sum all the values, and then multiply the sum by negative one. 


To implement this, we will first write a couple of functions to do the calculations. We could do this without functions, but functions will allow us to handle cases where $p_i=0$, as will be the case in a couple of problems. The first function, \texttt{p\_logp()}, returns $0$ if $p$ is $0$, and returns \texttt{p*log(p)} otherwise. The \texttt{calc\_entropy()} function is a wrapper around \texttt{p\_logp()}, applying \texttt{p\_logp()} to each element of a vector of probabilities, summing the results, and multiplying the sum by $-1$.


```{r}
# returns 0 if p=0 otherwise return p*log(p)
p_logp <- function(p){
  if (p == 0) return(0)
  p*log(p)
}

# calc entropy wrapper
calc_entropy <- function(x){
  avg_logprob <- sum(sapply(x, p_logp)) # sum (p * log(p))
  (-1)*avg_logprob # multiply that sum by -1
}
```
Now back to the question at hand:
Suppose a four-sided die is loaded such that, when tossed onto a table, it shows “1” 20%, “2” 25%, “3” 25%, and “4” 30% of the time. What is the entropy of this die?
```{r}
probs <- c(0.2, 0.25, 0.25, 0.3) # make a vector of the probabilities
calc_entropy(probs) # find the entropy
```
This results in an entropy of 1.376.

## Exercise 3: Priors and over-/under-fitting
7M5 
Provide an informal explanation of why informative priors reduce overfitting.

A:
Overfitting when the model capture too much noise from data. This noise may not be present in new data therefore the model fails to correctly predict new data. Informative priors help the model be less excitable, tells the model to ignore too unrealistic values or at least lower the leverage those values have on the model. This improves predictions because the model captures less noise and learns the 'regular' properties of the data.  


7M6
Provide an informal explanation of why overly informative priors result in underfitting.

Priors that are too restrictive on parameter space prevents the model from learning about the sample data. We basically just get the prior distributions back without learning anything about the data that could help with future predictions. 
If priors are too concentrated we tell the model to ignore real patterns in the data which reduces predictive performance. 

Setting priors and other regularization is a balancing act to avoid both under and over fitting. 
## Exercise 4 Fictional Polynesian motutere
7H3
Consider three fictional Polynesian motutere. On each there is a Royal Ornithologist charged by the king with surveying the bird population. They have each found the following proportions of 5 important bird species:

```{r}

B <- c(0.2, 0.1, 0.15)

```

```{r}
# make it tidy
polynesian_islands1 <- polynesian_islands %>% 
  tidyr::pivot_longer(cols = A:E, names_to = "species", values_to = "prop")
print(polynesian_islands1)
```


Notice that each island sums to 1 (the proportion of each species sums to 1). 

This problem has two parts. It is not computationally complicated. But it is conceptually tricky. 

First, compute the entropy of each island’s bird distribution. Interpret these entropy values. 

Second, use each island’s bird distribution to predict the other two.
This means to compute the KL divergence of each island from the others, treating each island as if it were a statistical model of the other islands. You should end up with 6 different KL divergence values.

Which island predicts the others best? Why?

Part 1: calculate entropy for each island 
```{r}
# can use calc_entropy function from earlier
island_entropy <- polynesian_islands1 %>% group_by(islands) %>% summarise(entropy = calc_entropy(prop)) 
# Above (and in the video) I did this using the tidyverse frame work but you can also do this as a loop or with an apply function

```

Calculate KL divergence:

$$D_{KL} = \sum_i p_i (\log(p_i) - \log(q_i)) $$
```{r}
# write a function for KL
d_kl <- function(p, q){
  sum(p*(log(p) - log(q)))
}
```


```{r}
# here we ask how different the islands are, imagine one probability distribution is used to predict another. 

for(i in 1:3){
  for(j in setdiff(1:3, i)){
    print(paste0("the KL divergence between Island ", i, " and Island ", j, " is: ", d_kl(polynesian_islands1[polynesian_islands1$islands==i, "prop"], polynesian_islands1[polynesian_islands1$islands==j, "prop"])))
  }
}
```
Island 1 has the shortest distances (smallest divergence) when it is used as the model
