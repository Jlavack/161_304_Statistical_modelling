## Exercise 1: DAG frenzy: two roads DAG modification, 6M1
Modify the DAG on page 186 to include the variable V, an unobserved cause of C and Y: C ← V → Y. Reanalyze the DAG. How many paths connect X to Y? Which must be closed? Which variables should you condition on now?
```{r}
dag_186 <- dagitty("dag{
X <- U <- A -> C -> Y
U -> B <- C
X -> Y
U [unobserved]
}")
coordinates(dag_186) <- list(
x = c(A = 1, B = 1, C = 2, X = 0, Y = 2, U = 0),
y = c(A = 0, B = 2, C = 1, X = 4, Y = 4, U = 1))
drawdag(dag_186)
```
```{r}
dag_186_mod <- dagitty("dag{
X <- U <- A -> C -> Y
U -> B <- C
X -> Y
C <- V -> Y
U [unobserved]
V [unobserved]
}")
coordinates(dag_186_mod) <- list(
x = c(A = 1, B = 1, C = 2, X = 0, Y = 2, U = 0, V =3),
y = c(A = 0, B = 2, C = 1, X = 4, Y = 4, U = 1, V=2.5))
drawdag(dag_186_mod)
```
```{r}
paths(dag_186_mod, from = "X", to = "Y")
adjustmentSets(dag_186_mod, exposure = "X", outcome = "Y")
```
There are now 5 paths, 2 are open. Three paths are from the original graph and 2 new ones when V is added.

We only want to keep X -> Y open because it is the causal path of interest. (Test your knowledge: the other paths are called _____ because they are non-causal.)
Paths 2 and 3 are already closed because B is the collider. Path 5 is also closed because C is a collider too. Path 4 is open because A is a fork and C is a pipe in this path. To close this path we could condition on A or C but C is a collider in a different path so if we conditioned on C we'd be opening up a new path through V. Therefore, if we want to make inferences about the causal effets of X on Y we must only condition on A (if our DAG is correct). 


## Exercise 2: Multicollinearity, a bad practice, 6M2

Sometimes, in order to avoid multicollinearity, people inspect pairwise correlations among
predictors before including them in a model. This is a bad procedure, because what matters is the conditional association, not the association before the variables are included in the model. To highlight this, consider the DAG X → Z → Y. Simulate data from this DAG so that the correlation between X and Z is very large. Then include both in a model prediction Y. Do you observe any multicollinearity? Why or why not? What is different from the legs example in the chapter?

Simulate data
```{r}
set.seed(1988)
n = 1000 # samples
x = rnorm(n, mean = 0, sd = 1) # normal distribution
z = rnorm(n, mean = x, sd = 0.1) # based on DAG x -> z -> y ## in the recording I had a bigger SD (SD=1) here, play with this parameter to see how it effects the estimations in the model, and how the data changes
y = rnorm(n, mean = z, sd = 1) 
dat <- data.frame(x=x, z=z, y=y) # make data frame
cor( x, z ) # correlation

pairs(dat) # view the simulated data
```
Write a model regressing y on both x and z
```{r}
mod_6m2 <- quap(alist(
  y ~ dnorm( mu, sigma ),
  mu <- alpha + beta.x * x + beta.z * z,
  alpha ~ dnorm(0, 0.2),
  c(beta.x, beta.z) ~ dnorm( 0, 0.5 ),
  sigma ~ dexp(1)
), data = dat)

plot( precis( mod_6m2 ) )

```
Both Beta.x and beta.z have estimates with wide posterior distributions (when SD is smaller in z). As the sd of the distribution we are simulating z from decreases (becomes closer to the mean) the posterior of beta.z and beta.x get wider because the correlation between z and x increases.
